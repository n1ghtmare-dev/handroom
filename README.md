# Handroom

Браузерная музыкальная студия: распознавание двух рук с 21 точкой на каждой, 8 барабанных звуков, согласованные музыкальные сцены, воздушная клавиатура с удержанием нот и режим пентатонических жестов, терменвокс, 16-шаговый ритм и локальная запись аудио с экспортом WAV (или WebM/M4A, если декодирование записи не поддерживается браузером).

## Запуск

```sh
npm install
npm run build
npm run dev
```

`npm run build` копирует MediaPipe WASM и скачивает модель Google один раз. После этого модель и обработчик загружаются с того же сайта. Для камеры нужен HTTPS или localhost. Рекомендуется Chrome или Edge. Микрофон не требуется. Видео не передаётся на сервер; распознавание выполняется в Web Worker на устройстве.

## Управление

Основной режим «Инструменты» открывает синтезатор поверх видео на всё окно. Чёрные и белые клавиши играют настоящие хроматические ноты C4–C5; кнопки октавы меняют диапазон на C3–C4 или C5–C6. Сначала поднимите палец над пунктирной линией, затем опустите через неё. Нота удерживается до поднятия. Две руки могут играть одновременно; при потере рук, задержке кадров, уходе со вкладки или открытии диалога ноты отпускаются. Глубина движения относительно стола не измеряется: используется видимое движение вниз по изображению.

По умолчанию распознаются указательный и средний пальцы обеих рук. Можно оставить два указательных или включить все восемь пальцев. «Высота» регулирует положение инструмента в безопасной области над панелью управления. Подсвеченные ноты сочетаются с текущим аккордом, но разрешены все клавиши. В портретном режиме прямой игры видео заполняет экран с обрезкой краёв; это оставляет линии нажатия внутри изображения камеры.

«Барабаны» в этом режиме показывают восемь площадок: движение вниз через линию даёт один удар, для следующего нужно поднять палец. Скорость движения меняет силу атаки. Соседние пальцы, одновременно ударившие по одной площадке, не удваивают звук.

Прежняя версия доступна во вкладке «Жесты»: панели рук, четыре звука на каждой, соединение большого пальца с остальными. Восемь нот синтезатора там следуют за гармонией. Контрольная версия исходников закреплена Git-тегом `handroom-gestures-v1` на коммите `e2272d66de8fff7c4e8305df5a1360c236410938`; её опубликованная версия сохраняется в Sites.

В синтезаторе «Инструментов» белые клавиши: A S D F J K L ;, чёрные: W E T Y U. Ноты удерживаются до отпускания клавиши; работают мышь и сенсорный экран. В «Жестах» и барабанах A S D F J K L ; дают короткие звуки. Физические позиции работают и в русской раскладке. Пробел запускает аккомпанемент. Для самостоятельной игры его включать не нужно. В терменвоксе правая рука задаёт высоту ноты, левая громкость.

Кнопка полного экрана разворачивает всю студию вместе с инструментами и диалогами. «Ритм» и музыкальные сцены открываются наложениями поверх видео.

Настройки и ритм сохраняются в localStorage, записи — в IndexedDB. «Мои записи» позволяет прослушивать, скачивать и удалять их. Очистка данных браузера удалит локальные записи.

## Источники

Подход к распознаванию изучен в [Ekmand/gesture-synth](https://github.com/Ekmand/gesture-synth): MediaPipe Hand Landmarker, VIDEO mode, две руки, GPU с резервным CPU. Приложение, интерфейс, интерпретатор касаний, синтез звука и секвенсор реализованы отдельно. Исходные компоненты проекта не копируются.

- [Google MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)
- MediaPipe model: Google, float16 hand_landmarker, version 1.
- Manrope (SIL Open Font License), Phosphor Icons (MIT).

## Музыкальные сцены

Кнопка с названием сцены внизу открывает три согласованных набора: «Тёплый грув» (86 BPM, ля минор), «Светлый день» (104 BPM, до мажор) и «Ночной воздух» (72 BPM, ре минор). У каждого свой бит, свинг, басовая линия, четыре аккорда, основной тембр и пространство.

«Играть» запускает основу; бас и аккорды можно отключить. Синтезатор предлагает бархатные клавиши, деревянную маримбу и воздушный пэд. В режиме «Жесты» восемь нот синтезатора и ступени терменвокса подстраиваются под текущий аккорд через пентатонические наборы без соседних полутонов. Актуальные названия нот всегда видны на панелях рук.

«Помощь ритму» притягивает только близкие удары к свинговой сетке, добавляя не более 45 мс. Бас и бочка не идут в реверберацию; остальные инструменты имеют дозированные посылы. Эхо синхронизировано с темпом, закрытый хэт глушит открытый. Отдельные громкости ритма, баса, аккордов и мелодии сохраняются между сессиями.

`tests/music-browser.html` в локальном dev-сервере рендерит три сцены реальным движком через OfflineAudioContext, проверяет запас по пикам, RMS, постоянную составляющую и плотную полифонию; там можно прослушать и скачать WAV-примеры.

`tests/instrument-browser.html` проверяет реальный путь событий приложения через синтетические видео и результаты распознавания: отдельную ноту, аккорд, отпускание, потерю рук и остановку кадров. Аппаратная камера не запрашивается. `tests/responsive.html` показывает приложение во фрейме шириной 390 px.
